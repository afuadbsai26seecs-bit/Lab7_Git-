# Marks Calculator Project

## 1. Project Title

# Student Marks Calculator


## 2. Purpose

The purpose of this project is to calculate the average of four marks and find the highest mark using Python. This project also helps us learn basic Git and GitHub commands.

## 3. How to Run the Program

1. Install Python on your computer.
2. Open the terminal in the project folder.
3. Run the following command:

```bash
python marks.py
```

## 4. Example Input

The program uses four predefined marks:

```text
70, 82, 75, 93
```

## 5. Example Output

```text
Marks: [70, 82, 75, 93]
Average: 80.0
Highest Mark: 93
```
